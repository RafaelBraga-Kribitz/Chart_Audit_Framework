# KPIs

90 authored measures. Generated by `chart-expert/scripts/build_measures.py`. Do not edit by hand.

Each card has a formula whose inputs are named metrics (`_catalog/metrics.jsonl`), a direction, a leading or lagging label, and two charts: the communication chart for a dashboard, report, or story, and the analysis chart for a notebook.

Machine-readable: `_catalog/kpis.jsonl` (one KPI per line) and `_catalog/metrics.jsonl` (each metric with the KPIs that use it).
