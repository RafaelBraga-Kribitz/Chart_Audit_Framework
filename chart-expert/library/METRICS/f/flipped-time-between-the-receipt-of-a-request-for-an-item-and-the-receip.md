# Flipped time between the receipt of a request for an item and the receipt of the requested item through the inter-library loss system

Input used by one or more KPI formulas. Flipped time between the receipt of a request for an item and the receipt of the requested item through the inter-library loss system is the quantity as named, with its own unit and period, before it is combined.

Unit: as named.
