*Knowing* ***which chart to use***

There are ways to show data, but one of the hardest parts is choosing the right chart.

The Visual Vocabulary workbook by Andy Kriebel is very helpful for both beginners and experienced data visualizers. This workbook groups charts by the type of relationship you want to show in the data. This makes it easier to understand how charts work and when to use them.

## Why This Workbook Matters

Many new data visualizers focus on making dashboards look advanced.

Good visualisation is about helping people understand information faster and more clearly. The workbook helps by grouping charts into categories based on the story the data is trying to tell.

It encourages people to ask, “ *Which chart explains this data best?* ”

That is one of the important skills in data visualization.

## The Main Chart Categories

## Deviation

Used to show differences from a reference point like zero, a target or an average.

Examples:

- trade surplus and deficit
- climate change
- positive vs negative sentiment

Chart types include:

- Diverging Bar Chart
- Stacked Diverging Bar
- Spine Chart
- Filled Surplus/Deficit Line Chart

## Correlation

Used to show relationships between variables.

Examples:

- inflation and unemployment
- income and life expectancy

Chart types include:

- Scatterplot
- Bubble Chart
- Connected Scatterplot
- XY Heatmap
- Line + Column Chart

This category teaches people how to identify patterns and relationships in data.

## Change Over Time

Used to show trends and movement across time.

Examples:

- stock prices
- economic trends
- growth over years

Chart types include:

- Line Chart
- Area Chart
- Slope Chart
- Calendar Heatmap
- Timeline
- Fan Chart
- Stock Price Chart

This is one of the most important categories because time-based data appears in almost every industry.

## Ranking

Used when the position of items matters more than the exact value.

Examples:

- league tables
- election results
- top-performing products

Chart types include:

- Ordered Bar Chart
- Ordered Column Chart
- Lollipop Chart
- Dot Plot
- Bump Chart
- Slope Chart

Ranking charts help make comparisons easier and clearer.

## Distribution

Used to show how data values are spread.

Examples:

- income distribution
- age distribution
- score distribution

Chart types include:

- Histogram
- Box Plot
- Violin Plot
- Population Pyramid
- Cumulative Curve
- Dot Plot

This category helps explain patterns, ranges, clusters, and outliers.

## Part to Whole

Used to show how one thing is divided into parts.

Examples:

- budgets
- company structures
- election results

Chart types include:

- Pie Chart
- Doughnut Chart
- Treemap
- Sunburst
- Stacked Bar
- Waterfall
- Grid Plot

This category is useful for understanding composition and contribution.

## Magnitude

Used to compare size and quantity.

Examples:

- market capitalization
- production volume
- sales comparison

Chart types include:

- Bar Chart
- Column Chart
- Grouped Bar
- Grouped Column
- Bullet Chart
- Radar Chart
- Pictogram
- Lollipop Chart

This category contains some of the most commonly used business charts.

## Spatial

Used when geographic location is important.

Examples:

- population density
- election maps
- disaster impact
- regional sales

Chart types include:

- Choropleth Map
- Symbol Map
- Heat Map
- Cartogram
- Dot Density Map
- Contour Map

Spatial charts help reveal geographic patterns in data.

## Flow

Used to show movement between states, locations, or processes.

Examples:

- migration
- money movement
- trade
- information flow

Chart types include:

- Sankey Diagram
- Chord Diagram
- Network Diagram
- Waterfall Chart

These charts are useful for explaining transitions and connections.

## What New Data Visualizers Should Focus On

New data visualizers should focus on:

- choosing the right chart
- understanding storytelling
- reducing clutter
- improving readability
- understanding chart purpose
- learning how people read visual information

The goal is not to use the most advanced chart. The goal is to **communicate**

## What Experienced Data Visualizers Can Learn

visualizers can use this workbook to:

- explore new chart types.
- improve storytelling.
- experiment with different layouts.
- avoid repeating the same visuals.
- **communicate** insights more effectively

Sometimes a less common chart tells the story much better than a standard dashboard chart.
